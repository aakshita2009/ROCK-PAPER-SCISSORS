# Rock Paper Scissors Game

A browser game where you play Rock Paper Scissors against the computer.

## Features
- Computer picks randomly each round
- Shows the winner of every round
- Running score for you, the computer and draws
- Last 5 rounds history
- Keyboard shortcuts: R, P, S
- Reset score button
- Responsive layout

## Tech
HTML, CSS, JavaScript (no libraries)

## Run locally
Open `index.html` in a browser.
